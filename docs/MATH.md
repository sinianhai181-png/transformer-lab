# Transformer 数学与维度推导

本文配合 `../docs/TRANSFORMER.md` 的一手资料整理，聚焦**网页里每一步到底算了什么**。所有公式均可在 `js/engine.js` 中找到对应实现，标注约定与文档一致：`[论文]` / `[实现]` / `[解读]`。

## 0. 记号约定

| 符号 | 含义 | 网页默认值 |
| --- | --- | --- |
| `n` | 源序列长度 | 3 |
| `m` | 目标序列长度 | 3 |
| `d` | `d_model`，所有子层输出的统一维度 | 8 |
| `h` | 注意力头数 | 2 |
| `d_k = d/h` | 每头的 Query/Key 维度 | 4 |
| `d_ff` | FFN 中间层维度 | 16 |
| `V` | 词表大小 | 输入 token 去重后的数量 |
| `E` | 词嵌入矩阵，`V × d` | 随 seed 生成 |
| `T` | 温度系数（网页额外暴露的旋钮） | 1 |

所有张量省略 batch 维，用二维数组表示；矩阵 `M[i][j]` 的第 `i` 行对应第 `i` 个位置。

## 1. 输入：Embedding 与位置编码

### 1.1 词嵌入乘 √d

```
X[i] = E[token_i] · √d          X ∈ ℝ^(n×d)
```

`[论文]` 原文明确要求 "In the embedding layers, we multiply those weights by √d_model"。`[解读]` 常见解释是与正弦位置编码的量级匹配；论文只给出操作，没有论证原因，因此网页把它标为解读而非定论。

### 1.2 位置编码

`[论文]` 正弦绝对编码：

```
PE(pos, 2i)   = sin( pos / 10000^(2i/d) )
PE(pos, 2i+1) = cos( pos / 10000^(2i/d) )
```

三个性质：

1. **多频率指纹**：`i` 小时振荡快、`i` 大时振荡慢，`d` 个维度合起来给每个位置唯一向量。
2. **相对位置可线性表示**：对任意固定偏移 `k`，`PE(pos+k)` 可写成 `PE(pos)` 的线性函数（和角公式的直接结果）。
3. **不依赖查表**：理论上不受训练时最大长度限制；`[解读]` 实践中超出训练长度后效果仍会明显下降。

`[实现]` 哈佛代码把 PE 预计算成 `(1, max_len, d)` 的 buffer，`requires_grad_(False)`，不参与训练；加法顺序是 `x = embedding + PE`，之后才 dropout。网页省略 dropout 以便观察确定性数值。

**为什么必须有位置信息**：自注意力对输入顺序是置换不变的——打乱 token 顺序，输出作为集合完全相同。语言有顺序，所以必须显式注入位置。

### 1.3 加法后的输入

```
x₀ = X + PE                     x₀ ∈ ℝ^(n×d)
```

至此所有后续层输入输出形状都必须是 `n × d`——这是残差连接的**结构约束**。

## 2. 缩放点积注意力

### 2.1 Q / K / V 的角色

```
Q = x Wᴽ      K = x Wᴷ      V = x Wⱽ      ∈ ℝ^(n×d_k)
```

- **Query**：我在找什么信息
- **Key**：我提供什么信息的索引
- **Value**：我实际提供的内容

`[解读]` 可类比数据库检索，但注意匹配是**软**的：所有位置按权重贡献，不是硬选取。

### 2.2 五步计算

设 `Q ∈ ℝ^(n×d_k)`，`K ∈ ℝ^(m×d_k)`，`V ∈ ℝ^(m×d_v)`：

```
① S = Q Kᵀ                      S ∈ ℝ^(n×m)，S[i][j] = qᵢ · kⱼ
② S = S / (√d_k · T)            缩放（T 是网页额外暴露的温度）
③ S_masked = mask(S)            非法位置置 −1e9
④ A = softmax(S_masked)         沿 key 维归一化，每行和为 1
⑤ Output = A V                  ∈ ℝ^(n×d_v)，每个位置是所有 value 的凸组合
```

`softmax` 的稳定实现先减行最大值再取指数：

```
softmax(v)[j] = exp(v_j − max(v)) / Σ_k exp(v_k − max(v))
```

### 2.3 为什么除以 √d_k（最容易讲错的一处）

`[论文]` 脚注给出严格理由：若 `q`、`k` 各分量独立、均值 0、方差 1，则

```
Var(q · k) = Var(Σ_{i=1}^{d_k} qᵢ kᵢ) = d_k
```

`d_k` 越大，点积幅值越大，softmax 被推进**梯度极小的饱和区**，训练变慢甚至停滞。论文原文还给出实验观察：小 `d_k` 时两种注意力表现相近，`d_k` 大时**不加缩放的加性注意力反而优于点积注意力**。

所以准确说法是「控制方差、防止 softmax 饱和导致梯度消失」，而不是笼统的「防止数值溢出」。网页的「缩放与温度」实验用真实分数和模拟的 `d_k = 4/16/64/256` 两种视角展示这件事。

### 2.4 掩码

两类掩码作用不同：

| 类型 | 用在哪 | 规则 |
| --- | --- | --- |
| padding mask | 源序列与目标序列 | 屏蔽 `<pad>` 位置 |
| causal mask | **仅** decoder 自注意力 | 只允许 `j ≤ i` |

`[实现]` 因果掩码构造：

```
allowed(i, j) = (j <= i)
S[i][j] = allowed(i, j) ? S[i][j] : −1e9
```

论文写 `−∞`，哈佛代码用 `−1e9` 作为数值近似。**掩码在 softmax 之前生效**；attention dropout（网页省略）施加在 softmax **之后**的 `A` 上。

### 2.5 注意力权重不是解释性证据

`[解读]` 权重只是一次软路由，不等于因果重要性。把热力图里颜色深的格子直接说成"模型在关注这个词"是过度解读——这也是网页在每个热力图步骤下都加了提醒的原因。

## 3. 多头注意力

### 3.1 公式与维度

```
head_i = Attention(x Wᴽᵢ, x Wᴷᵢ, x Wⱽᵢ)
MultiHead(x) = Concat(head_1, …, head_h) Wᴼ
```

投影矩阵维度 `[论文]`：

```
Wᴽᵢ, Wᴷᵢ, Wⱽᵢ ∈ ℝ^(d × d_k)        Wᴼ ∈ ℝ^(h·d_v × d)
```

论文 base 模型：`h = 8`，`d_k = d_v = d/h = 64`。

### 3.2 张量形状链

`[实现]` 完整形状变化（`B` 为 batch，`L` 为序列长）：

```
(B, L, 512)  ──线性投影──►  (B, L, 512)
             ──view─────►  (B, L, 8, 64)
             ──transpose►  (B, 8, L, 64)
             ──attention─► scores (B, 8, L, L), context (B, 8, L, 64)
             ──transpose─► (B, L, 8, 64)
             ──view──────► (B, L, 512)
             ──Wᴼ───────►  (B, L, 512)
```

网页的「多头拼接」步骤直接展示 `Concat → n × (h·d_k) = n × d`，并注明这条形状链。

**为什么计算量没有爆炸**：每头维度缩小到 `1/h`，`h` 个头合起来与"单头用完整 `d` 维"基本持平。这是近乎免费的多视角。

**`Wᴼ` 不是多余的**：它把 `h` 个子空间的结果融合回统一表示。各头共享输入、只是投影不同，并不是 `h` 个小模型。

### 3.3 三种注意力对照

| 位置 | Q 来源 | K/V 来源 | 掩码 | 形状 |
| --- | --- | --- | --- | --- |
| Encoder 自注意力 | encoder 上一层 | encoder 上一层 | 无（双向） | `n × n` |
| Decoder 掩码自注意力 | decoder 上一层 | decoder 上一层 | causal + padding | `m × m` |
| Encoder–Decoder 交叉注意力 | **decoder** | **encoder 输出 Z** | 仅 padding | `m × n` |

第三行最容易记反：`[论文]` Q 来自解码器，K/V 来自编码器。它是源序列信息进入解码器的**唯一通道**。网页在交叉注意力的 K/V 来源处专门画了箭头。

## 4. 逐位置前馈网络 FFN

```
[论文]  FFN(x) = max(0, x W₁ + b₁) W₂ + b₂
        W₁ ∈ ℝ^(d × d_ff),  W₂ ∈ ℝ^(d_ff × d)
```

`d_ff = 4d` 是论文配置；`[解读]` 属于经验值，不是定理。网页默认 `d_ff = 2d` 是为了矩阵能在一屏内看清，可改成 4 倍。

**"逐位置"的含义**：同一个 FFN 独立作用于每个位置，位置之间不交互。序列内部的信息混合**完全由注意力完成**。实现上等价于对 `n × d` 做两次矩阵乘：

```
H₁ = act(x W₁ + b₁)     ∈ ℝ^(n × d_ff)
FFN(x) = H₁ W₂ + b₂     ∈ ℝ^(n × d)
```

`act` 在网页里可选 ReLU（论文）或 GELU（现代常见）。参数量上，每层 FFN 约为注意力的 2 倍，占每层参数的 2/3——它是参数的主要承载者。`[解读]` 一种有影响力的解释把 FFN 看作 key–value 记忆，但不是严格定理。

## 5. 残差连接与 LayerNorm

### 5.1 Post-Norm（论文）

```
y = LayerNorm(x + Sublayer(x))
```

### 5.2 Pre-Norm（哈佛实现 / 现代大模型）

```
y = x + Sublayer(LayerNorm(x))
... 栈末再补一次 LayerNorm
```

`[实现]` 哈佛注解的 `SublayerConnection` 实际是 Pre-Norm，代码注释承认 "for code simplicity the norm is first as opposed to last"。现代大模型普遍采用 Pre-Norm，因为深层训练更稳定。**"Transformer 用 Post-Norm"只对原论文成立，不对今天的实际实现成立。** 网页可一键切换两种模式对照。

### 5.3 LayerNorm 公式

沿单个位置的**特征维**做标准化，不依赖 batch 统计：

```
μ = (1/d) Σ_j x_j
σ² = (1/d) Σ_j (x_j − μ)²
LN(x)_j = γ · (x_j − μ) / √(σ² + ε) + β
```

网页固定 `γ = 1, β = 0, ε = 1e-6`；`[实现]` 论文与哈佛代码都使用可学习 γ/β，此处为了聚焦注意力而省略。

**残差的两个作用**：

1. 梯度有恒等通路，可无损回传，使深层堆叠可训练。
2. **结构约束**：`x` 与 `Sublayer(x)` 必须同维——这就是 `d_model` 贯穿全模型的原因。

## 6. 输出层

```
[论文]  logits = H · Eᵀ        H ∈ ℝ^(m × d)
        probs  = softmax(logits)
```

论文要求两个 embedding 层和 pre-softmax 线性层**共享同一个权重矩阵**，既减少参数量也改善泛化。`[实现差异]` 哈佛代码默认不共享，共享代码写在 `if False:` 块里。网页遵循论文，因此输出概率直接由 `Eᵀ` 决定，改 embedding 会同时影响输入和输出。

`[论文]` 训练时用 label smoothing `ε = 0.1`：正确词概率 `1−ε`，其余非 padding 词平分 `ε`。论文的观察很值得注意：这会让困惑度变差，但提高准确率和 BLEU——说明困惑度不是唯一指标。网页不做训练，因此不含 label smoothing。

## 7. 完整前向维度表

记 `n` = 源长，`m` = 目标长，`d` = `d_model`，`V` = 词表，`h` = 头数，`d_k = d/h`：

| 步骤 | 形状 |
| --- | --- |
| 源/目标 embedding + PE | `n × d` / `m × d` |
| Q/K/V 投影 | `n × d_k`（每头） |
| 自注意力分数 `QKᵀ` | `n × n` |
| 交叉注意力分数 | `m × n` |
| 注意力输出 `AV` | `n × d_k` |
| 多头拼接 | `n × h·d_k = n × d` |
| FFN 中间层 | `n × d_ff` |
| decoder 输出 H | `m × d` |
| 输出 logits | `m × V` |
