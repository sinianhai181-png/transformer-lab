# 拓展实验说明

五个实验都遵循同一条原则：**固定同一组权重，只改变被研究的那个变量**。这样热力图的差异可以归因到单一因素，而不是随机初始化的噪声。

## 实验 1：位置编码消融

- **操作**：保持 Q/K/V 权重、token 序列不变，分别用正弦绝对编码、可学习位置编码、无位置编码做三次前向。
- **观察**：三种注意力矩阵 `A` 的形状；最终表示 `Z` 与论文方案的 Frobenius 距离 `‖ΔZ‖_F`。
- **预期**：无位置编码时，注意力对位置顺序不敏感。把左侧 token 顺序打乱（例如 `love I transformer`）再运行，"无位置编码"组的输出作为集合几乎不变；另外两组会明显变化。
- **结论**：自注意力本身是置换不变的，位置信息必须显式注入。正弦编码的优势是确定性和理论上的长度外推；可学习编码更灵活但不能超出训练长度；`[解读]` 正弦编码在实践中外推效果也有限。

## 实验 2：因果掩码对比

- **操作**：同一串 token、同一组权重，只切换 Encoder（双向）与 Decoder（因果掩码）模式。
- **观察**：注意力矩阵上三角（未来位置）的颜色与权重和。
- **预期**：双向模式上三角有明显权重；因果模式上三角权重和约等于 `1e-16` 量级（网页显示 8 位小数时为 0）。
- **结论**：掩码在 softmax **之前**把未来位置置为 `−1e9`。训练时右移输入 + 因果掩码 + teacher forcing 保证每个位置只基于已知前缀计算损失，所以整句可以并行计算；推理仍然逐 token 串行，这一点常被误解。

## 实验 3：多头分工

- **操作**：把头数切换到 2 或 4，运行实验。若只有 1 头，界面会提示先切换。
- **观察**：每个头的注意力热力图、各头最大权重、头间差异 `‖A₁−A₂‖_F`。
- **预期**：不同头的权重分布通常明显不同；偶尔两个头很相似，这不是 bug——"头会分化出不同功能"是观察性结论，不是架构保证。
- **结论**：各头共享输入，只是投影矩阵不同；`d_k = d_model / h`，所以头数增加不显著增加计算量。各头结果必须经 `Wᴼ` 融合，不能理解为 `h` 个独立小模型。

## 实验 4：缩放与温度

- **操作**：用当前网络位置 0 的真实注意力分数，比较四条曲线：不缩放、除以 `√d_k`、`√d_k × T=0.5`、`√d_k × T=2`。
- **观察**：温度越低分布越尖锐（接近 one-hot），越高越平滑。下半部分模拟独立同分布的 `q`、`k`，展示 `d_k` 从 4 增到 256 时，未缩放的最大权重迅速趋近 1，缩放后保持温和。
- **结论**：`[论文]` 内积方差为 `d_k`，缩放是为了控制方差、避免 softmax 进入梯度极小的饱和区。论文原文还指出：大 `d_k` 时，不缩放的加性注意力反而优于点积注意力。

## 实验 5：注意力复杂度

- **操作**：打开「注意力复杂度」标签，无需改配置即可运行。
- **观察**：`n=2…16` 的分数格数 `n²` 曲线；当前配置的 Query 长度 × Key 长度；`n=64/512/1024` 时的格数表。
- **预期**：当前默认 cross 配置是 3×3 = 9 格；`n=64` 时单头已有 4096 格，`n=1024` 时为 1,048,576 格，再乘头数 h 与层数 N。
- **结论**：`[论文]` Table 1 给出自注意力层复杂度 `O(n²·d)`，循环层 `O(n·d²)`，逐位置 FFN `O(n·d²)`。当 `n < d` 时自注意力更省；长序列下 `n²` 成为主要瓶颈，稀疏注意力与线性注意力就是为了绕开这一项。本页玩具规模 `n ≤ 12`，平方项尚不明显，需要把 n 想象成 2048 才看得出量级。

## 复现建议

按这个顺序动手最能建立直觉：

1. 先把 token 改成两个词，头数设为 1，`d_model=4`，逐格读注意力矩阵。
2. 用「权重编辑器」把 `W_Q` 全改成 0，确认注意力退化为均匀分布，理解分数从哪来。
3. 应用「关注前一个 token」预设，观察对角线如何移动。
4. 打开因果掩码，确认上三角被清零。
5. 切换 Post/Pre-Norm，确认最终形状不变但数值改变。
6. 最后跑五个实验，把前面的观察串起来。

引擎与界面的每一步都可用 `npm test` 中的全部测试交叉验证。
